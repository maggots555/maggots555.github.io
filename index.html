Proyecto principal · OS-001

SIGMA

Sistema Integrado de Gestión Técnica y Control de Calidad. No es un CRUD de inventario: es el flujo completo del centro de servicio.

inventario-calidad-django

Producción

Del ingreso del equipo a la entrega, en un solo sistema.

SIGMA digitaliza el taller: 22 estados de orden, cotizador sincronizado con almacén, incidencias de calidad, cámara de evidencia, portal del cliente (PWA + push) y arquitectura multi-país (México, Argentina, Chile, Colombia).

El código vive en GitHub. GitHub Pages no puede ejecutar Django (necesita Python, PostgreSQL, Redis y Celery), por eso este portafolio es la vitrina y el repo es el taller.

  • Django 5.2
  • Python 3.12
  • TypeScript
  • PostgreSQL
  • Celery + Redis
  • PWA
  • Plotly / ML
